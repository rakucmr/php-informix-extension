# Code of conduct

## Our commitment

We want participation in this project to be professional, technical and
welcoming, regardless of experience, language, nationality, gender identity,
sexual orientation, disability, appearance or religion.

## Expected behavior

- Discuss code and behavior, not people.
- Give reproducible technical arguments and accept correction.
- Respect that maintainers cannot support every Informix/PHP combination.
- Do not publish another person's credentials, private data or identifying
  information.
- Do not use issues or pull requests for commercial promotion or harassment.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, deliberate disruption,
spam and publishing security details before a fix are not acceptable.

## Enforcement

Report concerns privately to the maintainer through the repository profile or
the private channel used for security reports. Reports are handled
confidentially. Maintainers may edit or remove comments, close issues, reject
contributions or block accounts when necessary.

This code applies in repository issues, pull requests, discussions and other
project spaces. It is a project policy, not legal advice.
