pdo_informix — the Informix PDO driver

The PDO driver underneath ifx_pdo and the PHP library. It provides the standard PDO API, LOB streams and direct Informix access through CSDK.

Overview

The PDO driver is the layer that talks directly to Informix Client SDK through ODBC. It does not expose the ifx_* functions: the application uses the standard PDO API, while ifx_pdo and the PHP library build the procedural compatibility on top.

  • Use it directly when you want PDO, prepared statements and LOB streams.
  • It is required by ifx_pdo and by the PHP library.
  • It does not need the ifx or ifx_pdo extension.
One driver, several APIs. If you have legacy ifx_connect() code, choose ifx_pdo, ifx or the library — not the raw PDO driver.

Build and install

Build the driver with the target PHP headers. On Windows, build.bat produces php_pdo_informix.dll; on Linux, phpize produces pdo_informix.so.

batbuild.bat
cd pdo_informix/extension
build.bat "C:\php-devel\devel\php-8.5.11-devel-vs17-x64" "C:\IBM\Informix_Client_SDK"

For PHP < 8.1 apply the JSON/BSON patch from docs/reference/pdo-informix-php7.patch; for PHP 7.0–7.4 also apply the linker patch.

bashbuild.sh
cd pdo_informix/src
phpize
./configure --with-pdo-informix=/opt/IBM/informix
make -j2

Install:

iniphp.ini
; php.ini
extension=pdo_informix
batverify
php -m | findstr /i pdo_informix
php -r "var_dump(PDO::getAvailableDrivers());"

Configuration

The driver has no ifx.* directives. Configure it through the DSN, environment variables and PDO attributes.

AttributeValueEffect
PDO::ATTR_ERRMODEPDO::ERRMODE_EXCEPTIONThrows exceptions on errors.
PDO::ATTR_DEFAULT_FETCH_MODEPDO::FETCH_ASSOCAssociative rows by default.
PDO::ATTR_PERSISTENTtrue / falsePersistent connections, if the driver supports them.
PDO::ATTR_TIMEOUTsecondsConnection timeout.
phppdo-options.php
$pdo = new PDO(
    getenv('PDO_INFORMIX_DSN'),
    getenv('PDO_INFORMIX_USER'),
    getenv('PDO_INFORMIX_PASS'),
    [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    ]
);
Short DSN vs full DSN. A DSN containing = is sent through SQLDriverConnect; the short form informix:testdb needs an odbc.ini entry.

Connecting

The full DSN is the most portable form. Use environment variables, not credentials in code.

phpconnect.php
$pdo = new PDO(
    getenv('PDO_INFORMIX_DSN'), // informix:server=...;database=...;host=...;service=...;protocol=olsoctcp;
    getenv('PDO_INFORMIX_USER'),
    getenv('PDO_INFORMIX_PASS')
);
DSN formExample
Fullinformix:server=ids;database=db;host=127.0.0.1;service=9088;protocol=olsoctcp;
Shortinformix:db@ids (needs odbc.ini)

Complete example

phppdo_informix.php
<?php

$pdo = new PDO(
    getenv('PDO_INFORMIX_DSN'),
    getenv('PDO_INFORMIX_USER'),
    getenv('PDO_INFORMIX_PASS'),
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$stmt = $pdo->query(
    'select tabid, tabname from systables where tabid <= 5 order by tabid'
);

foreach ($stmt as $row) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

$pdo->beginTransaction();
$pdo->exec("insert into ifx_example (name) values ('pdo')");
$pdo->commit();

API reference

The driver exposes the PDO API, not the ifx_* functions. If you need the procedural API, use ifx_pdo, ifx or the library.

APIDescription
new PDO($dsn, $user, $password, $options)Opens the connection; options are PDO attributes.
PDO::query($sql)Executes a statement and returns a PDOStatement.
PDO::exec($sql)Executes a statement without a result; returns affected rows.
PDO::prepare($sql, $options)Prepares a statement; execute with execute().
PDOStatement::execute($params)Executes the statement, with optional parameters.
PDOStatement::fetch($mode)Fetches one row in the requested mode.
PDOStatement::fetchAll($mode)Fetches all rows.
PDOStatement::rowCount() / columnCount()Affected rows / column count.
PDOStatement::closeCursor()Closes the cursor and releases resources.
PDOStatement::bindValue() / bindParam()Binds values or references, including PDO::PARAM_LOB.
PDOStatement::getColumnMeta($n)Column metadata, when the driver provides it.
PDO::beginTransaction() / commit() / rollBack()PDO transactions.
PDO::lastInsertId(), quote(), errorInfo()Standard PDO helpers.

LOBs and SLOBs

TEXT/BYTE/CLOB/BLOB are read as PDO streams; JSON/BSON are returned as strings. For inserts use PDO::PARAM_LOB with a stream.

phplob.php
$fp = fopen('php://temp', 'r+');
fwrite($fp, "binary\0data");
rewind($fp);

$stmt = $pdo->prepare('insert into ifx_lob (payload) values (?)');
$stmt->bindValue(1, $fp, PDO::PARAM_LOB);
$stmt->execute();

$row = $pdo->query('select payload from ifx_lob')->fetch(PDO::FETCH_ASSOC);
echo stream_get_contents($row['payload']);

Transactions and errors

phptransaction.php
try {
    $pdo->beginTransaction();
    $pdo->exec("insert into ifx_t (name) values ('one')");
    $pdo->commit();
} catch (Throwable $e) {
    if ($pdo->inTransaction()) {
        $pdo->rollBack();
    }
    throw $e;
}

Testing

The driver suite has 9 tests and 198 assertions. It runs against the real server, with the DSN and credentials from the environment. The extension must be loaded explicitly if it is not in php.ini.

batrun-tests.bat
set PDO_INFORMIX_DSN=informix:server=<server>;database=<database>;host=<host>;service=<service>;protocol=olsoctcp;
set PDO_INFORMIX_USER=<user>
set PDO_INFORMIX_PASS=<password>
php -d extension_dir=C:\php\ext -d extension=pdo_informix pdo_informix/test/run-tests.php
bashrun-tests.sh
export PDO_INFORMIX_DSN='informix:server=<server>;database=<database>;host=<host>;service=<service>;protocol=olsoctcp;'
export PDO_INFORMIX_USER='<user>'
export PDO_INFORMIX_PASS='<password>'
php -d extension=pdo_informix pdo_informix/test/run-tests.php
Real tests. They run DML, LOBs and cursors. t07_lob_trigger and t08_merge intentionally keep diagnostic tables; clean the test database afterwards.

Troubleshooting

SymptomCause / fix
The module does not loadCheck NTS/ZTS, x64 and the PHP version; a DLL built for another version will not load.
CSDK missing at runtimeAdd %INFORMIXDIR%\bin (Windows) or $INFORMIXDIR/lib (Linux) to PATH/LD_LIBRARY_PATH.
Server not foundCheck INFORMIXSERVER, INFORMIXSQLHOSTS and the sqlhosts entry.
Linker 14.29 vs 14.16PHP 7.0–7.4: apply ifx_pdo_informix/tools/patch-pe-linker.ps1 to the DLL.
could not find driverpdo_informix is not loaded or is not in extension_dir.
IM002 on ODBCThe ODBC driver name must be exact, for example IBM INFORMIX ODBC DRIVER (64-bit).

Limitations

  • It does not provide the ifx_* functions; use one of the other modules for those.
  • The ODBC fallback is experimental and does not provide complete metadata.
  • JSON/BSON columns are returned as strings, not streams.
