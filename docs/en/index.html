PHP 7.0–8.5 · Windows & Linux

Informix for modern PHP, without compromises.

The procedural ifx_* API from 2005, available on PHP 7.0–8.5. Choose the PDO driver, ifx_pdo, the pure PHP library or the direct ifx variant — same semantics, same results, on Windows and Linux.

Modules

Four modules, one API

Each folder stands on its own, yet all share the same semantics and integration tests.

pdo_informix

PDO driver

The foundation: the Informix PDO driver with compatibility patches for PHP 7.0–8.5. ifx_pdo and the PHP library go through it; direct ifx does not.

C · PDOOpen ifx

ifx (direct CSDK)

C extension with all 39 functions, directly over the CSDK CLI: LOBs, CHAR, SLOB, scroll, metadata and SQLCA, with no pdo_informix. Loads with extension=ifx.

C · CSDKOpen ifx_pdo

ifx_pdo (pdo based)

C extension over PDO: ifx_* functions, Zend resources, INI directives. It needs php_pdo_informix.dll and loads with extension=ifx_pdo.

C · resourcesOpen php_informix

PHP library

The same semantics without compilation. One require and the global functions are available; links and results are PHP objects, while LOB/CHAR/SLOB handles stay integer ids.

Quick start

First query

Four ways to reach the same database: the PDO driver, direct ifx over CSDK, ifx_pdo over PDO and the PHP library. Keep the DSN and credentials in the environment.

phpquickstart.php
<?php
require __DIR__ . '/php_informix/src/autoload.php';

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

$res = ifx_query('select tabid, tabname from systables', $conn, IFX_SCROLL);

while (($row = ifx_fetch_row($res)) !== false) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

ifx_free_result($res);
ifx_close($conn);
phpifx_pdo.php
<?php
/*
 * Windows php.ini:
 *   extension=pdo_informix
 *   extension=ifx_pdo
 *
 * Linux php.ini:
 *   extension=pdo_informix.so
 *   extension=ifx_pdo.so
 *
 * CLI Windows:
 *   php -d extension=pdo_informix -d extension=ifx_pdo ifx_pdo.php
 *
 * CLI Linux:
 *   php -d extension=pdo_informix.so -d extension=ifx_pdo.so ifx_pdo.php
 */

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

$res = ifx_query('select tabid, tabname from systables', $conn, IFX_SCROLL);

while (($row = ifx_fetch_row($res)) !== false) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

ifx_free_result($res);
ifx_close($conn);

phppdo.php
<?php
$pdo = new PDO(
    getenv('PDO_INFORMIX_DSN'),
    getenv('PDO_INFORMIX_USER'),
    getenv('PDO_INFORMIX_PASS')
);

$stmt = $pdo->query('select tabid, tabname from systables');
foreach ($stmt as $row) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

The ifx_pdo and ifx examples show in their comments how to load the extension, both through php.ini and with -d extension. Complete build commands are in the documentation.
