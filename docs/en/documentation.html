Choose a module

Four implementations, the same Informix database. Each page is self-contained and can be read without the others.

pdo_informix

pdo_informix — the Informix PDO driver

The PDO driver underneath ifx_pdo and the PHP library. It provides the standard PDO API, LOB streams and direct Informix access through CSDK.

C · PDOOpenifx_pdo

ifx_pdo — the ifx API over PDO

A C extension that exposes all 39 ifx_* / ifxus_* functions over pdo_informix. It has Zend resources, INI directives and an embedded PHP engine.

C · PDOOpenifx

ifx — the direct CSDK extension

An independent C extension directly over the Informix Client SDK CLI. It implements all 39 functions without PDO and without pdo_informix.

C · CSDKOpenphp_informix

php_informix — the pure PHP library

The same 39 functions without compilation: one require over pdo_informix. Links and results are PHP objects.

PHP · PDOOpen

Contributing

Report the PHP version, NTS/ZTS, OS, binary and the minimal command that reproduces the issue. For library changes, regenerate the embedded source and run the affected suites.

Full pull-request and reporting instructions are in CONTRIBUTING.md and SECURITY.md in the repository root.
