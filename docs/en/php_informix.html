Overview

The library reimplements the procedural API in pure PHP over the PDO driver. Nothing is compiled: one require defines the 39 global functions. Links are Informix\Connection objects, results are Informix\Result, and LOB/CHAR/SLOB handles stay integer identifiers, as in the extension.

  • Suitable for simple deployment, shared hosting and prototypes.
  • Requires pdo_informix and ext-pdo.
  • It does not conflict with the C extension: functions are defined only if they do not already exist.
Objects at the surface, handles in the API. ifx_connect() returns an object, but ifx_create_blob() returns an integer id used by ifx_get_blob().

Build and install

Nothing is compiled. Copy the php_informix/ directory into the project or install it with Composer, then load the autoloader.

phprequire.php
require __DIR__ . '/php_informix/src/autoload.php';
bashcomposer
composer require informix/ifx-compat

The pdo_informix driver is still required. Verify:

bashverify
php -r "var_dump(PDO::getAvailableDrivers());"

Configuration

The library reads the same environment variables as the extension, but you can also set them through Informix\Config. It has no INI directives.

phpconfig.php
Informix\Config::set('nullformat', 1);
Informix\Config::set('charasvarchar', 1);
Informix\Config::set('connect_timeout', 5);

Recognised variables: IFX_BLOBINFILE, IFX_TEXTASVARCHAR, IFX_BYTEASVARCHAR, IFX_CHARASVARCHAR, IFX_NULLFORMAT, IFX_HTMLTBL_ESCAPE, IFX_ALLOW_PERSISTENT, IFX_CONNECT_TIMEOUT, IFX_DEFAULT_DATABASE, IFX_DEFAULT_USER, IFX_DEFAULT_PASSWORD, IFX_DEFAULT_HOST, IFX_HOST, IFX_SERVICE, IFX_PROTOCOL, IFX_USE_ODBC, DB_LOCALE, CLIENT_LOCALE.

Connecting

The library returns an Informix\Connection object; the rest of the API stays procedural.

phpconnect.php
require __DIR__ . '/php_informix/src/autoload.php';

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

var_dump($conn instanceof Informix\Connection); // true

Complete example

phpifx_example.php
<?php

require __DIR__ . '/php_informix/src/autoload.php';

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

$res = ifx_query(
    'select tabid, tabname from systables where tabid <= 5 order by tabid',
    $conn,
    IFX_SCROLL
);

echo 'Coloane: ', ifx_num_fields($res), PHP_EOL;

while (($row = ifx_fetch_row($res)) !== false) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

ifx_free_result($res);
ifx_close($conn);

API reference

All 39 functions are global and keep the original signatures. Links and results are resources in ifx_pdo/ifx, and objects in the library; LOB/CHAR/SLOB handles are integer identifiers.

Connection

FunctionDescription
ifx_connect($database, $userid, $password)Opens a connection; cached by DSN + user + password.
ifx_pconnect($database, $userid, $password)Persistent connection via PDO::ATTR_PERSISTENT.
ifx_close($link = null)Closes the given link or the default connection.

Queries and results

FunctionDescription
ifx_query($query, $link, $cursor_type, $blobidarray)Prepare + execute; accepts IFX_SCROLL/IFX_HOLD and blob values.
ifx_prepare($query, $link, $cursor_type, $blobidarray)Prepare only; execute with ifx_do().
ifx_do($result)Executes a prepared statement; can re-execute a cursor.
ifx_fetch_row($result, $position = null)Next row, or the row at the given scroll position.
ifx_htmltbl_result($result, $options = null)Renders the result as an HTML table.
ifx_free_result($result)Frees the result and the statement.
ifx_num_rows($result)Number of rows fetched so far.
ifx_num_fields($result)Number of columns.
ifx_affected_rows($result)Rows affected by the last DML statement.

Metadata and errors

FunctionDescription
ifx_fieldtypes($result)Map column name → SQL type (e.g. SQLCHAR).
ifx_fieldproperties($result)Properties: type, length, precision, scale, nullability.
ifx_getsqlca($result)Approximation of sqlca: sqlerrd1/sqlerrd2.
ifx_error($link = null)Status of the last operation: ' ', W, E or N.
ifx_errormsg($errorcode = null)Error message for the code, or the last error.

Constants: IFX_SCROLL, IFX_HOLD and IFX_LO_* are defined by the library. ifx_connect() returns Informix\Connection, ifx_query() returns Informix\Result, and LOB/CHAR/SLOB handles stay integer ids.

LOBs and SLOBs

By default, blobinfile=0 in Informix\Config: the row contains a blob id, and ifx_get_blob() returns the content. Set it with Informix\Config::set('blobinfile', 1) or the legacy function.

phplob-insert.php
$text = ifx_create_blob(1, 0, 'Hello from ifx-compat!');
$bytes = ifx_create_blob(0, 0, "binary\0data");

$res = ifx_query(
    'insert into ifx_lob (txt, byt) values (?, ?)',
    $conn,
    [$text, $bytes]
);
echo ifx_affected_rows($res);
ModeSettingResult
Blob iddefaultInteger; ifx_get_blob() returns the content.
Stringifx_textasvarchar(1) / ifx_byteasvarchar(1)Content directly in the row.
Fileifx_blobinfile_mode(1)ifx_get_blob() returns a temporary file path.
phplob-read.php
ifx_blobinfile_mode(1);
$row = ifx_fetch_row(ifx_query('select txt from ifx_lob', $conn));
echo file_get_contents(ifx_get_blob($row['txt']));

$ch = ifx_create_char('value');
ifx_update_char($ch, 'updated');
echo ifx_get_char($ch);
ifx_free_char($ch);

SLOBs are client-side buffers, not server-side ifx_lo_* objects. For large files, file mode avoids duplicating memory.

Transactions and errors

phperrors.php
$res = @ifx_query('select * from missing_table', $conn);
if ($res === false) {
    echo ifx_error(), PHP_EOL;      // E, W or N
    echo ifx_errormsg(), PHP_EOL;   // driver message
}

ifx_query('begin work', $conn);
// ...
ifx_query('commit work', $conn);

Cursors do not survive a COMMIT; re-read the result after commit. ifx_getsqlca() provides sqlerrd1 and sqlerrd2 for the last DML.

Testing

The library suite has 93 passing tests and 1 skipped (UTF-8 on an en_US.819 database). It runs over PDO, without a C extension; the driver must be loaded.

powershellrun-tests.ps1
$env:INFORMIXDIR = 'C:\IBM\informix'
$env:INFORMIXSERVER = '<server>'
$env:INFORMIXSQLHOSTS = 'C:\IBM\informix\etc\sqlhosts'
$env:IFX_TEST_DSN = '<database>@<server>'
$env:IFX_TEST_USER = '<user>'
$env:IFX_TEST_PASSWORD = '<password>'

php -d extension=pdo_informix php_informix/tests/run-tests.php
Real tests. The suites create temporary tables, run DML, LOBs and cursors, then clean up. They do not use mocks.

Troubleshooting

SymptomCause / fix
The module does not loadCheck NTS/ZTS, x64 and the PHP version; a DLL built for another version will not load.
CSDK missing at runtimeAdd %INFORMIXDIR%\bin (Windows) or $INFORMIXDIR/lib (Linux) to PATH/LD_LIBRARY_PATH.
Server not foundCheck INFORMIXSERVER, INFORMIXSQLHOSTS and the sqlhosts entry.
could not find driverInstall pdo_informix or set IFX_USE_ODBC=1 for the experimental fallback.
Missing autoloadInclude php_informix/src/autoload.php before the first call.
Long-running workersCall Informix\Api::reset() between requests.

Limitations

  • It runs over PDO, so it has overhead compared with the direct C extension.
  • It requires pdo_informix and ext-pdo.
  • In long-running workers, Api::reset() must be called.
