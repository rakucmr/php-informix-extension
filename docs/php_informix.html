Prezentare

Biblioteca reimplementează API-ul procedural în PHP pur, peste driverul PDO. Nu compilați nimic: un require definește cele 39 de funcții globale. Link-urile sunt obiecte Informix\Connection, rezultatele sunt Informix\Result, iar handle-urile LOB/CHAR/SLOB rămân identificatori întregi, ca în extensie.

  • Potrivit pentru deployment simplu, shared hosting și prototipuri.
  • Necesită pdo_informix și ext-pdo.
  • Nu intră în conflict cu extensia C: funcțiile sunt definite doar dacă nu există deja.
Obiecte la suprafață, handle-uri în API. ifx_connect() întoarce un obiect, dar ifx_create_blob() întoarce un id întreg folosit de ifx_get_blob().

Compilare și instalare

Nu se compilează nimic. Copiați directorul php_informix/ în proiect sau instalați-l cu Composer, apoi încărcați autoload-ul.

phprequire.php
require __DIR__ . '/php_informix/src/autoload.php';
bashcomposer
composer require informix/ifx-compat

Driverul pdo_informix rămâne obligatoriu. Verificați:

bashverify
php -r "var_dump(PDO::getAvailableDrivers());"

Configurare

Biblioteca citește aceleași variabile de mediu ca extensia, dar le poți seta și prin Informix\Config. Nu are directive INI.

phpconfig.php
Informix\Config::set('nullformat', 1);
Informix\Config::set('charasvarchar', 1);
Informix\Config::set('connect_timeout', 5);

Variabile recunoscute: IFX_BLOBINFILE, IFX_TEXTASVARCHAR, IFX_BYTEASVARCHAR, IFX_CHARASVARCHAR, IFX_NULLFORMAT, IFX_HTMLTBL_ESCAPE, IFX_ALLOW_PERSISTENT, IFX_CONNECT_TIMEOUT, IFX_DEFAULT_DATABASE, IFX_DEFAULT_USER, IFX_DEFAULT_PASSWORD, IFX_DEFAULT_HOST, IFX_HOST, IFX_SERVICE, IFX_PROTOCOL, IFX_USE_ODBC, DB_LOCALE, CLIENT_LOCALE.

Conectare

Biblioteca întoarce un obiect Informix\Connection; restul API-ului rămâne procedural.

phpconnect.php
require __DIR__ . '/php_informix/src/autoload.php';

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

var_dump($conn instanceof Informix\Connection); // true

Exemplu complet

phpifx_example.php
<?php

require __DIR__ . '/php_informix/src/autoload.php';

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

$res = ifx_query(
    'select tabid, tabname from systables where tabid <= 5 order by tabid',
    $conn,
    IFX_SCROLL
);

echo 'Coloane: ', ifx_num_fields($res), PHP_EOL;

while (($row = ifx_fetch_row($res)) !== false) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

ifx_free_result($res);
ifx_close($conn);

Referință API

Toate cele 39 de funcții sunt globale și au semnăturile extensiei originale. Link-urile și rezultatele sunt resurse în ifx_pdo/ifx, respectiv obiecte în bibliotecă; handle-urile LOB/CHAR/SLOB sunt identificatori întregi.

Conexiune

FuncțieDescriere
ifx_connect($database, $userid, $password)Deschide o conexiune; cache după DSN + user + parolă.
ifx_pconnect($database, $userid, $password)Conexiune persistentă prin PDO::ATTR_PERSISTENT.
ifx_close($link = null)Închide link-ul dat sau conexiunea implicită.

Interogări și rezultate

FuncțieDescriere
ifx_query($query, $link, $cursor_type, $blobidarray)Prepare + execute; acceptă IFX_SCROLL/IFX_HOLD și blob-uri.
ifx_prepare($query, $link, $cursor_type, $blobidarray)Doar prepare; execuția se face cu ifx_do().
ifx_do($result)Execută un statement pregătit; poate re-executa cursorul.
ifx_fetch_row($result, $position = null)Următorul rând sau rândul de la poziția dată (scroll).
ifx_htmltbl_result($result, $options = null)Randează rezultatul ca tabel HTML.
ifx_free_result($result)Eliberează rezultatul și statement-ul.
ifx_num_rows($result)Numărul de rânduri citite până acum.
ifx_num_fields($result)Numărul de coloane.
ifx_affected_rows($result)Rândurile afectate de ultimul DML.

ifx_errormsg($errorcode = null)Mesajul de eroare pentru codul dat sau ultima eroare.

ifx_update_blob($bid, $content)Înlocuiește conținutul unui blob.
ifx_copy_blob($bid)Copiază un blob și întoarce noul id.

Constante: IFX_SCROLL, IFX_HOLD și IFX_LO_* sunt definite de bibliotecă. ifx_connect() întoarce Informix\Connection, ifx_query() întoarce Informix\Result, iar handle-urile LOB/CHAR/SLOB rămân id-uri întregi.

LOB-uri și SLOB

Implicit, blobinfile=0 în Informix\Config: rândul conține blob id, iar ifx_get_blob() întoarce conținutul. Setarea se face cu Informix\Config::set('blobinfile', 1) sau cu funcția legacy.

phplob-insert.php
$text = ifx_create_blob(1, 0, 'Hello from ifx-compat!');
$bytes = ifx_create_blob(0, 0, "binary\0data");

$res = ifx_query(
    'insert into ifx_lob (txt, byt) values (?, ?)',
    $conn,
    [$text, $bytes]
);
echo ifx_affected_rows($res);
ModSetareRezultat
Blob idimplicitÎntreg; ifx_get_blob() întoarce conținutul.
Stringifx_textasvarchar(1) / ifx_byteasvarchar(1)Conținutul direct în rând.
Fișierifx_blobinfile_mode(1)ifx_get_blob() întoarce calea unui fișier temporar.
phplob-read.php
ifx_blobinfile_mode(1);
$row = ifx_fetch_row(ifx_query('select txt from ifx_lob', $conn));
echo file_get_contents(ifx_get_blob($row['txt']));

$ch = ifx_create_char('value');
ifx_update_char($ch, 'updated');
echo ifx_get_char($ch);
ifx_free_char($ch);

SLOB-urile sunt bufferi client-side, nu obiecte ifx_lo_* pe server. Pentru fișiere mari, modul fișier evită dublarea memoriei.

Tranzacții și erori

phperrors.php
$res = @ifx_query('select * from missing_table', $conn);
if ($res === false) {
    echo ifx_error(), PHP_EOL;      // E, W or N
    echo ifx_errormsg(), PHP_EOL;   // driver message
}

ifx_query('begin work', $conn);
// ...
ifx_query('commit work', $conn);

Cursoarele nu supraviețuiesc unui COMMIT; după commit recitiți rezultatul. ifx_getsqlca() oferă sqlerrd1 și sqlerrd2 pentru ultimul DML.

Testare

Suita bibliotecii are 93 de teste trecute și 1 sărit (UTF-8 pe o bază en_US.819). Rulează prin PDO, fără extensie C; driverul trebuie încărcat.

powershellrun-tests.ps1
$env:INFORMIXDIR = 'C:\IBM\informix'
$env:INFORMIXSERVER = '<server>'
$env:INFORMIXSQLHOSTS = 'C:\IBM\informix\etc\sqlhosts'
$env:IFX_TEST_DSN = '<database>@<server>'
$env:IFX_TEST_USER = '<user>'
$env:IFX_TEST_PASSWORD = '<password>'

php -d extension=pdo_informix php_informix/tests/run-tests.php
Teste reale. Suitele creează tabele temporare, rulează DML, LOB-uri și cursoare, apoi curăță datele. Nu folosesc mock-uri.

Măsurat pe PHP 8.5.11 NTS x64, Informix IDS 14.10.FC12, local, fără rețea între client și server. Valorile sunt orientative; recompilați și remăsurați în mediul vostru.

Depanare

SimptomCauză / soluție
Modulul nu se încarcăVerificați NTS/ZTS, x64 și versiunea PHP; un DLL construit pentru altă versiune nu se încarcă.
Lipsește CSDK la runtimeAdăugați %INFORMIXDIR%\bin (Windows) sau $INFORMIXDIR/lib (Linux) în PATH/LD_LIBRARY_PATH.
Serverul nu este găsitVerificați INFORMIXSERVER, INFORMIXSQLHOSTS și intrarea din sqlhosts.
could not find driverInstalați pdo_informix sau setați IFX_USE_ODBC=1 pentru fallback-ul experimental.
Autoload lipsăIncludeți php_informix/src/autoload.php înainte de primul apel.
Workeri de lungă duratăApelați Informix\Api::reset() între requesturi.

Limitări

  • Rulează peste PDO, deci are overhead față de extensia C directă.
  • Necesită pdo_informix și ext-pdo.
  • În workers de lungă durată trebuie apelat Api::reset().
