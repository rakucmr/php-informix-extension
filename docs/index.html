Informix pentru PHP modern, fără compromisuri.

Module

pdo_informix

Driverul PDO

Fundația: driverul PDO pentru Informix, cu patch-urile de compatibilitate PHP 7.0–8.5. Varianta ifx_pdo și biblioteca PHP trec prin el; varianta directă ifx nu.

C · PDODeschide ifx

ifx (direct CSDK)

Extensie C cu toate cele 39 de funcții, direct peste CSDK CLI: LOB-uri, CHAR, SLOB, scroll, metadate și SQLCA, fără pdo_informix. Se încarcă cu extension=ifx.

C · CSDKDeschide ifx_pdo

ifx_pdo (pdo based)

Extensie C peste PDO: funcții ifx_*, resurse Zend, directive INI. Necesită php_pdo_informix.dll; se încarcă cu extension=ifx_pdo.

C · resurseDeschide php_informix

Biblioteca PHP

Aceeași semantică, fără compilare. Un require și funcțiile globale sunt disponibile; link-urile și rezultatele sunt obiecte PHP, iar handle-urile LOB/CHAR/SLOB rămân id-uri întregi.

Start rapid

Primul query

Patru moduri de a ajunge la aceeași bază: driverul PDO, ifx direct peste CSDK, ifx_pdo peste PDO și biblioteca PHP. Setați DSN-ul și credențialele în mediu.

phpquickstart.php
<?php
require __DIR__ . '/php_informix/src/autoload.php';

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

$res = ifx_query('select tabid, tabname from systables', $conn, IFX_SCROLL);

while (($row = ifx_fetch_row($res)) !== false) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

ifx_free_result($res);
ifx_close($conn);
phpifx_pdo.php
<?php
/*
 * Windows php.ini:
 *   extension=pdo_informix
 *   extension=ifx_pdo
 *
 * Linux php.ini:
 *   extension=pdo_informix.so
 *   extension=ifx_pdo.so
 *
 * CLI Windows:
 *   php -d extension=pdo_informix -d extension=ifx_pdo ifx_pdo.php
 *
 * CLI Linux:
 *   php -d extension=pdo_informix.so -d extension=ifx_pdo.so ifx_pdo.php
 */

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

$res = ifx_query('select tabid, tabname from systables', $conn, IFX_SCROLL);

while (($row = ifx_fetch_row($res)) !== false) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

ifx_free_result($res);
ifx_close($conn);

phppdo.php
<?php
$pdo = new PDO(
    getenv('PDO_INFORMIX_DSN'),
    getenv('PDO_INFORMIX_USER'),
    getenv('PDO_INFORMIX_PASS')
);

$stmt = $pdo->query('select tabid, tabname from systables');
foreach ($stmt as $row) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}
