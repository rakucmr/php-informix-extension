pdo_informix

pdo_informix — driverul PDO pentru Informix

Driverul PDO care stă la baza lui ifx_pdo și a bibliotecii PHP. Oferă API-ul PDO standard, stream-uri pentru LOB-uri și acces direct la Informix prin CSDK.

C · PDODeschideifx_pdo

ifx_pdo — API-ul ifx peste PDO

Extensie C care expune toate cele 39 de funcții ifx_* / ifxus_* peste pdo_informix. Are resurse Zend, directive INI și un motor PHP încorporat.

C · PDODeschideifx

ifx — extensia directă peste CSDK

Extensie C independentă, direct peste Informix Client SDK CLI. Implementează toate cele 39 de funcții, fără PDO și fără pdo_informix.

C · CSDKDeschidephp_informix

php_informix — biblioteca PHP pură

Aceleași 39 de funcții, fără compilare: un singur require peste pdo_informix. Link-urile și rezultatele sunt obiecte PHP.
