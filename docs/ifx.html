ifx — extensia directă peste CSDK

Extensie C independentă, direct peste Informix Client SDK CLI. Implementează toate cele 39 de funcții, fără PDO și fără pdo_informix.

Prezentare

Varianta directă implementează toate cele 39 de funcții în C, peste API-ul CLI al CSDK. Nu folosește PDO, nu încorporează motorul PHP și nu depinde de pdo_informix. Este cea mai independentă cale, cu cel mai mic overhead între PHP și CSDK.

  • Potrivit pentru producție fără PDO și pentru aplicații legacy.
  • Se încarcă singur, cu extension=ifx.
  • Nu se poate încărca împreună cu ifx_pdo.
Testat pe Windows x64. Suita directă are 102/102 pe PHP 7.0–8.5. Pentru Linux există scriptul build-ifx-linux.sh, dar rezultatele din matricea de compatibilitate sunt cele Windows.

Compilare și instalare

Varianta directă se compilează cu header-ele PHP-ului țintă și cu CSDK. Nu are nevoie de pdo_informix.

batbuild-ifx.bat
cd ifx_informix
build-ifx.bat "C:\php-devel\devel\php-8.5.11-devel-vs17-x64"
bashbuild-ifx-linux.sh
cd ifx_informix
IFX_CSDK=/opt/IBM/informix ./build-ifx-linux.sh

Pentru PHP 7.0–7.4, DLL-ul trebuie marcat cu versiunea de linker a PHP-ului: 14.0 pentru 7.0/7.1, 14.16 pentru 7.2–7.4. tests/run-native.ps1 -Build o face automat.

iniphp.ini
; php.ini
extension=ifx
batverify
php -m | findstr /i ifx
php -r "var_dump(extension_loaded('ifx'), function_exists('ifx_connect'));"

Configurare

Varianta directă nu înregistrează directive ifx.*. Modurile se setează prin funcții, iar conectarea implicită prin variabilele de mediu ale procesului.

SetareCum
Bază / server implicitIFX_DEFAULT_DATABASE, INFORMIXDATABASE
Utilizator / parolăIFX_DEFAULT_USER, IFX_DEFAULT_PASSWORD
Mod LOBifx_blobinfile_mode(), ifx_textasvarchar(), ifx_byteasvarchar()
CHAR / NULLifx_charasvarchar(), ifx_nullformat()
Fără INI, cu intenție. Opțiunile se aplică explicit în cod, ca să nu depindă de ordinea de încărcare a modulelor.

Conectare

Varianta directă acceptă aceleași trei argumente. Dacă lipsesc, citește variabilele de mediu; nu are nevoie de PDO.

phpconnect.php
$conn = ifx_connect(
    getenv('IFX_DSN'),       // database@server
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

Exemplu complet

phpifx_example.php
<?php

/*
 * Windows php.ini:  extension=ifx
 * Linux php.ini:    extension=ifx.so
 */

$conn = ifx_connect(
    getenv('IFX_DSN'),
    getenv('IFX_USER'),
    getenv('IFX_PASSWORD')
);

$res = ifx_query(
    'select tabid, tabname from systables where tabid <= 5 order by tabid',
    $conn,
    IFX_SCROLL
);

echo 'Coloane: ', ifx_num_fields($res), PHP_EOL;

while (($row = ifx_fetch_row($res)) !== false) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

ifx_free_result($res);
ifx_close($conn);

Referință API

Toate cele 39 de funcții sunt globale și au semnăturile extensiei originale. Link-urile și rezultatele sunt resurse în ifx_pdo/ifx, respectiv obiecte în bibliotecă; handle-urile LOB/CHAR/SLOB sunt identificatori întregi.

Conexiune

FuncțieDescriere
ifx_connect($database, $userid, $password)Deschide o conexiune nouă către baza indicată.
ifx_pconnect($database, $userid, $password)Refolosește conexiunea cu aceleași argumente în request (fără PDO).
ifx_close($link = null)Închide link-ul dat sau conexiunea implicită.

Interogări și rezultate

FuncțieDescriere
ifx_query($query, $link, $cursor_type, $blobidarray)Prepare + execute; acceptă IFX_SCROLL/IFX_HOLD și blob-uri.
ifx_prepare($query, $link, $cursor_type, $blobidarray)Doar prepare; execuția se face cu ifx_do().
ifx_do($result)Execută un statement pregătit; poate re-executa cursorul.
ifx_fetch_row($result, $position = null)Următorul rând sau rândul de la poziția dată (scroll).
ifx_htmltbl_result($result, $options = null)Randează rezultatul ca tabel HTML.

ifx_num_rows($result)Numărul de rânduri citite până acum.
ifx_num_fields($result)Numărul de coloane.
ifx_affected_rows($result)Rândurile afectate de ultimul DML.

Constante: IFX_SCROLL, IFX_HOLD și IFX_LO_* sunt definite de extensie. Link-urile și rezultatele sunt resurse; handle-urile LOB/CHAR/SLOB sunt identificatori întregi.

LOB-uri și SLOB

Implicit, blobinfile=0: rândul conține blob id, iar ifx_get_blob() întoarce conținutul din memorie. ifx_blobinfile_mode(1) trece pe fișier temporar.

phplob-insert.php
$text = ifx_create_blob(1, 0, 'Hello from ifx-compat!');
$bytes = ifx_create_blob(0, 0, "binary\0data");

$res = ifx_query(
    'insert into ifx_lob (txt, byt) values (?, ?)',
    $conn,
    [$text, $bytes]
);
echo ifx_affected_rows($res);
ModSetareRezultat
Blob idimplicitÎntreg; ifx_get_blob() întoarce conținutul.
Stringifx_textasvarchar(1) / ifx_byteasvarchar(1)Conținutul direct în rând.
Fișierifx_blobinfile_mode(1)ifx_get_blob() întoarce calea unui fișier temporar.
phplob-read.php
ifx_blobinfile_mode(1);
$row = ifx_fetch_row(ifx_query('select txt from ifx_lob', $conn));
echo file_get_contents(ifx_get_blob($row['txt']));

$ch = ifx_create_char('value');
ifx_update_char($ch, 'updated');
echo ifx_get_char($ch);
ifx_free_char($ch);

SLOB-urile sunt bufferi client-side, nu obiecte ifx_lo_* pe server. Pentru fișiere mari, modul fișier evită dublarea memoriei.

Tranzacții și erori

phperrors.php
$res = @ifx_query('select * from missing_table', $conn);
if ($res === false) {
    echo ifx_error(), PHP_EOL;      // E, W or N
    echo ifx_errormsg(), PHP_EOL;   // driver message
}

ifx_query('begin work', $conn);
// ...
ifx_query('commit work', $conn);

Cursoarele nu supraviețuiesc unui COMMIT; după commit recitiți rezultatul. ifx_getsqlca() oferă sqlerrd1 și sqlerrd2 pentru ultimul DML.

Testare

Suita directă are 102 verificări și nu depinde de pdo_informix. A fost rulată pe PHP 7.0–8.5 x64, cu 102/102 pe fiecare versiune.

powershellrun-native.ps1
$env:INFORMIXDIR = 'C:\IBM\informix'
$env:INFORMIXSERVER = '<server>'
$env:INFORMIXSQLHOSTS = 'C:\IBM\informix\etc\sqlhosts'
$env:IFX_TEST_DSN = '<database>@<server>'
$env:IFX_TEST_USER = '<user>'
$env:IFX_TEST_PASSWORD = '<password>'

.\ifx_informix\tests\run-native.ps1 `
  -Php C:\php\php.exe `
  -Dll C:\path\to\ifx.dll
Teste reale. Suitele creează tabele temporare, rulează DML, LOB-uri și cursoare, apoi curăță datele. Nu folosesc mock-uri.

Limitări

  • Nu folosește PDO; nu poate partaja conexiuni/atribute PDO.
  • Nu se încarcă împreună cu ifx_pdo.
  • Testele din matrice sunt pe Windows x64; build-ul Linux este separat.
