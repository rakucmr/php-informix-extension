pdo_informix — driverul PDO pentru Informix

Driverul PDO care stă la baza lui ifx_pdo și a bibliotecii PHP. Oferă API-ul PDO standard, stream-uri pentru LOB-uri și acces direct la Informix prin CSDK.

Prezentare

Driverul PDO este stratul care vorbește direct cu Informix Client SDK prin ODBC. Nu expune funcțiile ifx_*: aplicația folosește API-ul PDO standard, iar ifx_pdo și biblioteca PHP construiesc compatibilitatea procedurală peste el.

  • Îl folosești direct dacă vrei PDO, prepared statements și stream-uri LOB.
  • Este obligatoriu pentru ifx_pdo și pentru biblioteca PHP.
  • Nu are nevoie de extensia ifx sau ifx_pdo.
Un singur driver, mai multe API-uri. Dacă ai cod vechi cu ifx_connect(), alege ifx_pdo, ifx sau biblioteca — nu driverul PDO direct.

Compilare și instalare

Compilați driverul cu header-ele PHP-ului țintă. Pe Windows, build.bat produce php_pdo_informix.dll; pe Linux, phpize produce pdo_informix.so.

batbuild.bat
cd pdo_informix/extension
build.bat "C:\php-devel\devel\php-8.5.11-devel-vs17-x64" "C:\IBM\Informix_Client_SDK"

Pentru PHP < 8.1 aplicați patch-ul JSON/BSON din docs/reference/pdo-informix-php7.patch; pentru PHP 7.0–7.4 aplicați și patch-ul de linker.

bashbuild.sh
cd pdo_informix/src
phpize
./configure --with-pdo-informix=/opt/IBM/informix
make -j2

Instalare:

iniphp.ini
; php.ini
extension=pdo_informix
batverify
php -m | findstr /i pdo_informix
php -r "var_dump(PDO::getAvailableDrivers());"

Configurare

Driverul nu are directive ifx.*. Configurarea se face prin DSN, variabile de mediu și atribute PDO.

AtributValoareEfect
PDO::ATTR_ERRMODEPDO::ERRMODE_EXCEPTIONAruncă excepții la erori.
PDO::ATTR_DEFAULT_FETCH_MODEPDO::FETCH_ASSOCRânduri asociative implicit.
PDO::ATTR_PERSISTENTtrue / falseConexiuni persistente, dacă driverul le suportă.
PDO::ATTR_TIMEOUTsecundeTimeout de conectare.
phppdo-options.php
$pdo = new PDO(
    getenv('PDO_INFORMIX_DSN'),
    getenv('PDO_INFORMIX_USER'),
    getenv('PDO_INFORMIX_PASS'),
    [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    ]
);
DSN scurt vs DSN complet. Un DSN care conține = este trimis prin SQLDriverConnect; forma scurtă informix:testdb are nevoie de o intrare în odbc.ini.

Conectare

DSN-ul complet este cea mai portabilă formă. Folosiți variabile de mediu, nu credențiale în cod.

phpconnect.php
$pdo = new PDO(
    getenv('PDO_INFORMIX_DSN'), // informix:server=...;database=...;host=...;service=...;protocol=olsoctcp;
    getenv('PDO_INFORMIX_USER'),
    getenv('PDO_INFORMIX_PASS')
);

Exemplu complet

phppdo_informix.php
<?php

$pdo = new PDO(
    getenv('PDO_INFORMIX_DSN'),
    getenv('PDO_INFORMIX_USER'),
    getenv('PDO_INFORMIX_PASS'),
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$stmt = $pdo->query(
    'select tabid, tabname from systables where tabid <= 5 order by tabid'
);

foreach ($stmt as $row) {
    echo $row['tabid'], ' ', $row['tabname'], PHP_EOL;
}

$pdo->beginTransaction();
$pdo->exec("insert into ifx_example (name) values ('pdo')");
$pdo->commit();

Referință API

Driverul expune API-ul PDO, nu funcțiile ifx_*. Dacă ai nevoie de API-ul procedural, folosește ifx_pdo, ifx sau biblioteca.

PDO::query($sql)Execută un statement și întoarce PDOStatement.

LOB-uri și SLOB

TEXT/BYTE/CLOB/BLOB se citesc ca stream-uri PDO; JSON/BSON se întorc ca string. Pentru inserare folosiți PDO::PARAM_LOB cu un stream.

phplob.php
$fp = fopen('php://temp', 'r+');
fwrite($fp, "binary\0data");
rewind($fp);

$stmt = $pdo->prepare('insert into ifx_lob (payload) values (?)');
$stmt->bindValue(1, $fp, PDO::PARAM_LOB);
$stmt->execute();

$row = $pdo->query('select payload from ifx_lob')->fetch(PDO::FETCH_ASSOC);
echo stream_get_contents($row['payload']);

Tranzacții și erori

phptransaction.php
try {
    $pdo->beginTransaction();
    $pdo->exec("insert into ifx_t (name) values ('one')");
    $pdo->commit();
} catch (Throwable $e) {
    if ($pdo->inTransaction()) {
        $pdo->rollBack();
    }
    throw $e;
}

Testare

Suita driverului are 9 teste și 198 de aserțiuni. Rulează real împotriva serverului, cu DSN-ul și credențialele din mediu. Extensia trebuie încărcată explicit dacă nu este în php.ini.

batrun-tests.bat
set PDO_INFORMIX_DSN=informix:server=<server>;database=<database>;host=<host>;service=<service>;protocol=olsoctcp;
set PDO_INFORMIX_USER=<user>
set PDO_INFORMIX_PASS=<password>
php -d extension_dir=C:\php\ext -d extension=pdo_informix pdo_informix/test/run-tests.php
bashrun-tests.sh
export PDO_INFORMIX_DSN='informix:server=<server>;database=<database>;host=<host>;service=<service>;protocol=olsoctcp;'
export PDO_INFORMIX_USER='<user>'
export PDO_INFORMIX_PASS='<password>'
php -d extension=pdo_informix pdo_informix/test/run-tests.php
Teste reale. Rulează DML, LOB-uri și cursoare. Testele t07_lob_trigger și t08_merge păstrează intenționat tabele de diagnostic; curățați baza de test după rulare.

Limitări

  • Nu oferă funcțiile ifx_*; pentru acestea folosiți unul dintre celelalte module.
  • Fallback-ul ODBC este experimental și nu oferă metadate complete.
  • Coloanele JSON/BSON se întorc ca string, nu ca stream.
